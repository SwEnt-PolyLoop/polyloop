# The LLM proposal does not see the parties' split proposals

Gemini gets the condition photos, the item (title, description, value), the deposit and the rental's dates, but not the split proposals exchanged during direct settlement, nor the chat. Given the history, a model tends to split the difference between the last two offers instead of judging the photos, and a party could make an extreme proposal just before escalating to pull the result their way. The LLM proposal is meant as an independent second opinion, based on the evidence only. Do not add the history back without revisiting this.
